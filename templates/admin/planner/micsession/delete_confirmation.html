{% extends "admin/delete_confirmation.html" %} {% comment %} Typed-name confirmation for deleting a Mic Session. Deleting a session takes every mic assignment, presenter slot, note and photo under it. It used to be a trash icon in the session header on the tracker, 40px from the A1/A2 tabs, on a row that gets tapped all day to collapse and expand sessions -- one mis-tap from losing a day's work, behind a browser confirm() that is dismissed reflexively. The delete now lives only here, in the session's Settings, and this page makes you type the session's name before the button will submit. Django's own summary of what is about to be deleted is left exactly as it is above the gate. This is a guard against a mis-tap, not an access control -- who may delete is decided by BaseEquipmentAdmin.has_delete_permission, server side. Hence a JavaScript gate: it is applied on load, so a browser without JS simply gets Django's normal confirmation page rather than an unusable one. {% endcomment %} {% block extrahead %}{{ block.super }} {% endblock %} {% block content %}{{ block.super }} {% endblock %}
