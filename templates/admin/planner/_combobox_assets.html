{% comment %} Shared combobox for the free-text signal-name fields: a filterable panel over any whose this page also renders. Included by device_input_grid.html, device_output_grid.html, p1_input_inline.html and galaxy_input_inline.html. Two of those appear on the same change page, so the script installs itself once (window flag) and then enhances every input[list] in the document. The panel is appended to and positioned fixed. It used to be an absolutely positioned child of the input's wrapper, which the I/O device grid clipped to an invisible ~52px sliver: both .device-{input,output}-cell (overflow: hidden, from the Safari fixed-layout fix in PR #78) and Django admin's own .form-row (overflow: hidden, forms.css) cut it off. Neither of those rules can go -- the 8-column grid alignment depends on the first -- so the panel leaves the clipping context instead. Rows are grouped by console: one non-selectable sticky header per console, then its channels as "Ch 9 · Wless 9". Options that carry no data-console (the p1/galaxy datalists, which are bare names) render as one ungrouped, headerless list exactly as before. {% endcomment %}
