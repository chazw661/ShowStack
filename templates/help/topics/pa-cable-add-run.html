Log each speaker cable run from the amp racks to the boxes, so ShowStack can total up what to pull from stock.

Steps

  1. Open PA Cable Entries in the sidebar and tap Add PA Cable Entry.
  2. Pick an Entry mode:
    • Free text: choose a Label (zone, e.g. HL; + adds a new one) and type the Destination.
    • From Soundvision / Amps: choose an Array / Speaker (linked) from an uploaded prediction and a Destination amp (linked). The array's speakers are listed beside them.
  3. Set Count (identical runs), Length (ft) per run and Cable.
  4. Add Notes, a Drawing Ref or a Color if you want them, then Save. You stay on the run so you can add fan-outs.

Good to know

  • Length is required for every cable type except NL4 Jumper.
  • You can edit Count and Length straight from the list.
  • The Duplicate selected cable runs action copies fan-outs, but not extensions or couplers.
