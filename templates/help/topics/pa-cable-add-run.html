Log each speaker cable run from the amps to the boxes, so ShowStack can total up what to pull from stock and draw it on the Wiring Diagram.

Steps

  1. Open PA Cable Entries in the sidebar and tap Add PA Cable Entry.
  2. In From, pick the amp the cable leaves, or a whole rack (the first entry under each rack).
  3. Choose a Cable Label (e.g. HL; + adds a new one) and type To: the speaker or fan-out it goes to, e.g. KIVA DELAY 2 & 3.
  4. If the show has a Soundvision report, you can link the speaker arrays the run feeds. Their speakers are listed below.
  5. Set Count, Length (ft) per run and Cable, then Save. You stay on the run to add fan-outs.

Good to know

  • A new run needs a From and a To. To can stay blank if you link an array.
  • Runs saved before this form keep working as they are.
  • Length is required for every cable type except NL4 Jumper.
  • Duplicating a run copies its fan-outs and linked arrays, but not extensions or couplers.
