Build a Clear-Com Arcadia or FreeSpeak II setup in ShowStack, then export it as a config file for the base station.

Steps

  1. Open COMM Configurations in the sidebar.
  2. Click + New Configuration and choose Arcadia Base Station or FreeSpeak II.
  3. Type a name when asked for Config name:, e.g. "Main Stage Arcadia". The editor opens.
  4. Work through the Partylines, Roles and Ports tabs, then export.

Good to know

  • A new Arcadia starts with four partylines (PL 1–PL 4), four 2-wire ports, eight 4-wire ports and no roles.
  • A new FreeSpeak II starts with twelve channels (Channel 1–Channel 12), four 2-wire ports and four 4-wire ports.
  • Every config in the project shows as a card with its Lines, Roles and Sessions counts. Click a card to open it. Use ← All Configs to go back.
  • To start from a saved setup instead, use Templates.
  • Delete removes the config for good, after you confirm.
  • HelixNet is listed but marked Soon, so it can't be chosen yet.
