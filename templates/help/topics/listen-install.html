ShowStack Listen runs on the wired Mac at the RF rack. It takes the receiver outputs (Dante Virtual Soundcard or any interface) and streams one pack to an A2's phone over the show Wi-Fi. Audio never goes through ShowStack.

Steps

  1. On the rack Mac, open the Mic Tracker and press 🎧 Listen Setup.
  2. Choose Download ShowStack Listen. Unzip it, drag it to Applications and open it once.
  3. When macOS asks, allow microphone access. macOS uses that name for every audio input, DVS included. [CHECK]
  4. Back in Listen Setup, press ▶ Start on this Mac. Allow the browser to open the app, then confirm the show in the app.
  5. Choose the input from the 🎧 menu bar icon under Audio Input.

Good to know

  • When it's working, the status line reads Running with the input name and the number of listeners.
  • Start on this Mac appears only on a Mac, not on an iPad or phone. The download is built for Apple silicon Macs.
  • The app has no Dock icon, only 🎧 in the menu bar. Turn on Open at Login there for a rack Mac that should always be ready.
