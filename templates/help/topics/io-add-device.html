Add each stage box, rack or interface once, with its input and output count, so you can patch and label its ports.

Steps

  1. Open I/O Devices in the sidebar and press Add I/O Device. Editors and owners only.
  2. Type a Name (for example "Stage Left rack") and pick a Location if you use them.
  3. Add Primary IP Address and Secondary IP Address if the box is on the network.
  4. Set Input count and Output count.
  5. Press Save. The device opens with its ports laid out eight to a row: In 1, In 2 … and Out 1, Out 2 …
  6. Name the ports (see "Patch stage box inputs to console channels" and "Label stage box outputs") and press Save.

Good to know

  • Get the counts right first time: once the device is saved, its page has no Input count or Output count field.
  • The Location list shows this project's locations only.
