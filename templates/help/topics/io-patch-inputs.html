Name each stage box input after the console channel it feeds. Picking the channel from the list also links the port to it.

Steps

  1. Open I/O Devices in the sidebar and open the device.
  2. Under I/O Device Inputs, tap the box under In 1. The list shows every named channel on this project's consoles, grouped by console, for example "Ch 3 · Kick".
  3. Type to narrow it by console, channel number or name.
  4. Tap a channel (or use the arrow keys and Enter).
  5. Do the rest of the ports, then press Save.

Good to know

  • Picked means linked. If the channel is renamed on the console, the port's name follows. The console's Patch column and the device PDF's Console Source show the link.
  • A typed name is a name only, even if it matches a channel exactly.
  • Editing a picked name, even retyping it, drops the link and keeps what you typed. Pick from the list again to relink.
  • Clearing the box clears the name and the link.
  • If the channel is deleted, the port keeps its name but loses the link.
  • Only the A Source names are offered; Source (B) names are not in the list.
