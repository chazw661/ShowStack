Name each stage box input after the console channel it feeds; picking the channel also links the port to it.

Steps

  1. Open I/O Devices in the sidebar and open the device.
  2. Under I/O Device Inputs, tap the box under In 1. The list shows every named channel on this project's consoles, grouped by console ("Ch 3 · Kick").
  3. Type to narrow it (console, channel number or name), then tap a channel.
  4. Do the rest of the ports, then press Save.

Good to know

  • Or patch from the console page: tap a channel's Patch cell. Both make the same link; unnamed channels can only be patched there.
  • Picked means linked: rename the channel and the port follows.
  • A typed name is a name only, even if it matches a channel exactly. Editing a picked name drops the link; pick again to relink. Clearing the box clears both.
  • "linked to … (unnamed)" in a box means it's patched to an unnamed channel. Leave it empty; typing over it unpatches it.
  • Amber name not saved: the name was typed on the console page and not saved there yet.
  • Only A Source names are offered.
