Each show lives in its own project. Everything you add (consoles, amps, mics, cable runs) goes into whichever project is currently open.

Steps

  1. On the Project Dashboard, tap + Create New Project.
  2. Fill in Name and, if you like, Start Date, End Date, Venue and Client. Tap Save.
  3. Back on the Project Dashboard, tap Open Project on the project's card. It becomes your open project and the System Overview opens.
  4. To switch later, pick another project from the Project dropdown in the header. On an iPad-sized screen it sits inside the menu under your name.

Good to know

  • Creating projects needs a paid or beta account. Free accounts can still join projects that other people share with them.
  • The header dropdown lists only the projects you own. To open a project someone shared with you, go to Project Dashboard and tap Open Project under Projects Shared With You.
  • If you don't own any projects, the header shows the open project's name instead of a dropdown.
  • Check the project name in the header before you add anything.
