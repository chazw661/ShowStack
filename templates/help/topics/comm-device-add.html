Add an intercom main station (an Arcadia, say) as a comm device, so its Dante channels, 4-wire ports and 2-wire ports can be patched.

Steps

  1. Open Devices in the sidebar and press Add comm device. Editors and owners only.
  2. Type a Name and pick a Location if you use them.
  3. Set Dante inputs, Dante outputs, 4-wire ports and 2-wire ports.
  4. Type its Dante network (for example "Comms 48k") and its IP addresses.
  5. Press Save. The device opens with a Comms patch section (see "Patch a comm device").

Good to know

  • To add or remove ports later, change a count and save. Clear a patched port before lowering its count.
  • Set Dante network on I/O devices too: it is on every device's page.
  • Comm device ports are not offered on the Console page or on amp and processor inputs.
  • COMM Config and the beltpack pages are separate and unchanged.
