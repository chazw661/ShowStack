The System Overview shows the whole open project on one screen. System PDF prints it as one report.

Steps

  1. Tap the ShowStack logo at top left. It also opens after Open Project on the Project Dashboard.
  2. The top row follows the signal flow: Consoles, I/O Devices, Processors, Amplifiers, PA Cable, Soundvision, Multitrack, each with counts. A lit dot means the module has something in it. Tap a card to open it.
  3. Below are COMM System, Mic Tracker (first five show days with mic counts), Power Distribution, IP Address Manager and Diagrammer.
  4. Tap System PDF to open the Complete System Report in a new tab: cover, contents, then Consoles, I/O Devices, System Processors, Amplifiers, PA Cable Schedule, COMM System, Power Distribution and Soundvision Predictions.

Good to know

  • The report always has every section; empty ones say so. There are no section toggles.
  • Mic Tracker isn't in the report; use the Mic Tracker's own exports.
  • Counts load when the page opens. Reload to refresh them.
  • 📱 Mobile shows a QR code for the mobile site.
