Save a console you build every show, then load a copy into any of your projects in a few taps.

Steps

  1. To save: open Consoles, tick the box beside one console, choose Save selected console as template from the Action menu and press Go.
  2. It goes into My templates, normally under the console's name.
  3. To load: switch to the project you want, open Consoles and press 📋 Load template.
  4. Press Preview load into … on the template you want.
  5. Check the Console name. If that name is already used in this project, a new one is suggested; change it if you like.
  6. Press Add to … to create the console. Editors and owners only.

Good to know

  • Loading only adds consoles. Nothing already in the project is changed or deleted.
  • A template copies the inputs, aux, matrix and stereo outputs, the IP addresses and the location. A missing location is created in the new project.
  • A template is a snapshot: later edits to the console do not change it.
  • Templates are yours, not the project's: only you see them, from any project.
  • Rename, add notes to or delete a template in My templates in the sidebar.
