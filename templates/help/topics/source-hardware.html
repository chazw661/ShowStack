The Source Hardware dropdown on console inputs lists mic and DI models. If yours isn't there, add it without leaving the console.

Steps

  1. Open a console. In the inputs list, open the Source Hardware dropdown on any row. Source Hardware (B) works the same way.
  2. Pick + Add new… at the bottom of the list, type the name (50 characters max) and tap OK.
  3. The new name is selected on that row and added to every Source Hardware dropdown on the page. Save the console as usual.
  4. To rename, reorder or delete names, tap Manage list in the Source Hardware column header, or open Source Hardware Options in the sidebar. Edit Sort order numbers and tap Save, or tap a name to rename or delete it.

Good to know

  • The list is shared by every project and every ShowStack account. If you rename or delete a name, it changes for everyone.
  • Inputs you already saved keep their name, even after it's renamed or deleted in the list.
  • Only project owners and editors can change the list; viewers can see it.
