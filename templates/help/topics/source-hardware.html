The Source Hardware dropdown on console inputs lists mic and DI models. If yours isn't there, add it without leaving the console.

Steps

  1. Open a console. In the inputs list, open the Source Hardware dropdown on any row. Source Hardware (B) works the same way.
  2. Pick + Add new… at the bottom of the list, type the name (50 characters max) and tap OK.
  3. The new name is selected on that row and added to every Source Hardware dropdown on the page. Save the console as usual.
  4. To see the whole list, tap Manage list in the Source Hardware column header, or open Source Hardware Options in the sidebar. You can add a name there too.

Good to know

  • The list is shared by every project and every ShowStack account. A name you add appears for everyone, at the end of the list.
  • Owners and editors of the project you're in can add names. Renaming, reordering and deleting names is for ShowStack administrators only, because it would change the list for everyone. Viewers can see the list.
  • Inputs you already saved keep their name, even if it's later renamed or deleted in the list.
