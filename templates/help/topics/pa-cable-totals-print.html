See how many cables to pull from stock, with a 20% spare, and print the schedule for the cable crew.

Steps

  1. Open PA Cable Entries and scroll below the list to Cable Summary with Ordering Calculations.
  2. For each cable type, read Total Runs and Total Length (ft), then CABLES NEEDED and ORDER QTY (+20% SAFETY) in 100', 50' and 25' lengths.
  3. Check the Fan Out Summary and the Quick Order List below it.
  4. Tap Export to PDF at the top for the printable schedule.

How runs become cables

  • Each run takes whole 100' cables while more than 100' remains. The leftover gets one more cable, the shortest that reaches. A 150' run is 100' + 50'. A 10' run takes a 25'.
  • Count multiplies the whole run: 4 × 50' is four 50' cables, not two 100'.

Good to know

  • The summary counts only the rows currently listed, so a Cable filter or a search changes it. The PDF always has every run.
  • Jumpers show "—" for length and get their order quantity from Count.
