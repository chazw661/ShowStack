Build a console's input list, so every channel has a name your stage boxes, PDFs and exports can use.

Steps

  1. Open Consoles in the sidebar and press Add Console. Editors and owners only.
  2. Fill in Name (for example "FOH PM7"). Location, Primary IP Address and Secondary IP Address are optional.
  3. Tap the Console inputs heading to open the grid. A new console starts with 144 numbered rows.
  4. Type each channel's name in Source. Add Source Hardware (the mic or DI), Group, Dca, Mute, Direct out and Omni in as needed.
  5. Press Save.

Good to know

  • A Inputs / B Inputs above the grid switch to each channel's B side (Source (B), Source Hardware (B)), for example a wireless backup.
  • Autofill in the Dante number and Input ch headers fills a run of rows with a number sequence (start value and step).
  • Pick + Add new… in a Source Hardware list to add your own mic or box; every row can use it straight away. Manage list in the header opens the full list.
  • Untick Multitrack to keep a channel out of multitrack sessions.
