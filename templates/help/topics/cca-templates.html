Save a config you use show after show, then start the next one from it instead of rebuilding partylines, roles and ports.

Steps

  1. Open the config and click Save as Template.
  2. Enter a Template Name (e.g. "Corporate Standard") and click Save Template.
  3. To use it, go back to ← All Configs and click Templates.
  4. Click Load next to the template and confirm or change the Config name:. A new config opens as a copy, ready to edit.

Good to know

  • A template copies the partylines, roles with all their keys, and the 2-wire and 4-wire port settings. Dante Channels are not copied.
  • Saving under a name that is already in use replaces the old template.
  • Templates belong to the project they were saved in. They don't appear in other projects.
  • Changing a config later does not change its template. Save again to update it.
  • The new config keeps the template's system type, Arcadia or FreeSpeak II.
