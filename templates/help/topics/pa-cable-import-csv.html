Bring in a whole cable schedule from a spreadsheet instead of typing each run.

Steps

  1. In PA Cable Entries, tap Import CSV.
  2. Tap Download sample CSV and fill it in. The columns are Label, Destination, Count, Cable, Length, Notes, Drawing Ref, Fan Outs, Extensions and Couplers.
  3. Choose the file under Select CSV file: and tap Import PA Cables.
  4. A message gives the number imported, any new zones and up to eight row problems.

Formats

  • Cable: a code or name, e.g. NL_4 or NL 4. The import page lists them all.
  • Fan Outs: NL4_Y x2; NL8_Y x1
  • Extensions: NL4_Y: NL4 25 x1. The length must be 25, 50, 100 or 150.
  • Couplers: NL4_COUPLER x1

Good to know

  • Every row needs a Label and a Cable. A blank Count imports as 1 and a blank Length as 0.
  • New labels become zones. Labels longer than 20 characters are cut short.
  • Imports add rows and never replace them. Importing the same file twice doubles your runs.
  • A bad row is skipped and the rest still import.
