The IP Address Manager lists the network address of every console, stage box, amp, processor and hardwired belt pack in the project. You can edit any of them from this one page.

Steps

  1. On the System Overview, tap the IP Address Manager card.
  2. Tap an address, or Click to add IP, and type the new one. Consoles and I/O devices have a Primary IP Address and a Secondary IP Address.
  3. Tap Save or press Enter. To back out, tap Cancel or press Esc. To remove an address, clear the box and save.
  4. Edit Details → opens that item's full page in a new tab.
  5. To export the list, tap Export PDF Report or Export CSV Spreadsheet.

Good to know

  • Duplicate addresses are not flagged. Nothing warns you when two devices share an IP, so check the list or the CSV yourself.
  • Only gear you've already added appears here. Add new devices in their own modules.
  • Wireless COMM roles appear under COMM Config headings so you can see them, but saving a change to one fails with an error.
  • Only hardwired belt packs are listed.
