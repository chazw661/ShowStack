Say what is plugged into each amp output and ShowStack shows the load the amp sees.

Steps

  1. Open Amplifier Assignments and find the amp.
  2. In Cabinets per output, pick a section, for example Kara II · LF. The list shows only cabinets that amp can drive.
  3. Use − and + to set how many are in parallel.
  4. Read the line underneath: Kara II · LF ×3 → 2.67 Ω (2.7 Ω). The bracket is the nearest published load.

Warnings

  • Over N per output or a red line such as Kara II: 8 on this amp, max 6: more than the L-Acoustics Preset Guide's drive-capacity table allows (v25.0, pp.119–120).
  • … does not drive this: the amp model changed and can't drive that cabinet.
  • Below … minimum: shown only for amps the table leaves out, such as the LA8.
  • No cabinet: nothing assigned yet.
  • An amber CH 1 is routed LF, cabinet is Kara II · HF means the Ch block disagrees; nothing changes on its own.
