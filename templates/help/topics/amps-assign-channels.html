Label what feeds each amp channel, which speaker zone it drives and what each output connector goes to.

Steps

  1. Open Amplifier Assignments and find the amp card.
  2. In the left column, fill in AVB stream, Analogue Input Label and AES Input Label for each channel.
  3. In the middle column, pick a setting for each Ch: PA, LF, HF or SB, with slot A–D (e.g. SB_A). The cabinets themselves go in the Cabinets per output strip below.
  4. In the right column, type what each output feeds under NL4 Out, CaCom Out or SC32 Out, whichever the amp model has.
  5. Each field saves when you leave it. A green flash means it saved, red means it didn't.

Good to know

  • Input fields suggest the output labels from your P1 and Galaxy processors (e.g. "AVB 3 - Sub L"). Tapping one clears it so the full list shows. Leave without picking and the old value comes back.
  • Rows with no AVB stream or analogue label fold away behind + N unused.
  • The card's NL4 Out 1–4 are separate from the NL4/NL8 pair fields in Deep edit. The amp PDF prints the card's values.
