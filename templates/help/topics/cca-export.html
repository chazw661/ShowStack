Download the finished config as a .cca file, ready to load onto the Arcadia or FreeSpeak II base station.

Steps

  1. Open the config and check the Partylines, Roles and Ports tabs.
  2. Click Export .cca.
  3. For Arcadia, a password warning appears first. Note the password, then click OK.
  4. The .cca file downloads, named after the config.
  5. Load it onto the base station using Clear-Com's own tools.

Good to know

  • The Arcadia warning reads: importing the file resets the Arcadia password to the factory default 04312B48. Have it to hand before you load the file on the unit.
  • Not every port setting reaches the Arcadia file. See "Assign ports".
  • Test the loaded config on the unit before the show.
