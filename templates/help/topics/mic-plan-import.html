Mic Planner reads a show day's run-of-show PDF and drafts the mic plan: which pack each person wears, and when the A2 mics and de-mics them.

Steps

  1. Open Mic Planner in the sidebar and pick the Day.
  2. Press Import showflow and choose the PDF. A file covering the same times as a part asks to Replace it or Add as a new part.
  3. Check People: merge duplicates, set HH or backup, Add person for anyone missing. Set packs, A2s and Pack use in Settings. Press Break on a segment heading to mark or unmark a break.
  4. Press Generate plan. Showflow + plan shows packs and A2 work at each line, Pack chart each RF across the day, Review what to check.
  5. Select a person or RF to highlight it everywhere.

Good to know

  • Editors and owners only; viewers can read the page.
  • The PDF is read and thrown away. Only its rows are kept.
  • Without send/catch cues, someone is on from a line naming them to an exit line or their segment's end.
  • After changing the showflow or people, Re-generate.
  • Merges, links and hints you set survive a re-import. Re-read with current rules (part menu) reads saved rows again.
