Mic Plan reads a show day's run-of-show PDF and shows who is on stage in each segment, from which line to which, and anything that does not add up. It does not change the Mic Tracker.

Steps

  1. Open Mic Plan in the sidebar and pick the Day.
  2. Press Import showflow and choose the PDF. If the day already has a part covering the same times, you are asked whether to Replace it or Add as a new part.
  3. Read Who's on stage: each segment lists its people, on and off by line. Anything to check sits at its line in amber.
  4. Select a person to highlight their lines, link a Presenter or set a mic hint. To merge a duplicate, press Merge a duplicate, then select it.
  5. If the file has send/catch cues, check Crew names.

Good to know

  • Editors and owners only; viewers can read the page.
  • The PDF is read and thrown away. Only its rows are kept.
  • Without cues, on and off come from segment times.
  • Merges, links and hints you set survive a re-import; everything else is read again.
  • After a ShowStack update, Re-read with current rules (part menu) reads the saved rows again.
