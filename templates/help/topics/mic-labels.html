Print a label for the outward-facing front of each bodypack, so whoever is micing a presenter can see whose pack it is at arm's length.

Steps

  1. In the Mic Tracker, open a session's A2 tab and press 🖨 Print labels.
  2. Choose what to print: One session, One day or Whole show.
  3. Choose a label style:
    • Single name prints one label per presenter. A pack's labels come out next to each other, in running order.
    • Running order prints one label per pack listing its presenters in order. For a whole show you get one label per pack per day.
  4. Pick Colour or Black & white, and the first unused label on the sheet under Start at label.
  5. Check the preview, then press ↓ Download PDF and print it.

Lining the print up with the labels

  1. Press Print alignment page and print it on plain paper at 100% / Actual size. Never use Fit to page.
  2. Measure both bars. Each should be exactly 100 mm. If not, the print was scaled: find the scaling setting in the print dialog.
  3. Hold the print over a sheet of labels against a window. If the outlines sit to one side, enter the difference under Printer calibration: +X moves the print right, +Y moves it down.
  4. The calibration is saved in this browser, so set it once per computer and printer.

Good to know

  • Labels are sized for OnlineLabels OL3016LP: 2" square weatherproof laser labels, 12 per US Letter sheet.
  • The number in the corner is the RF number, the same as the badge on the A2 card.
  • A presenter on the same pack for several sessions in a row gets one label (or one line) with the first session's time and "+2" for the sessions after it.
  • Empty presenter slots are skipped; the preview tells you how many.
  • Anyone who can see the project can print labels, including viewers.
