Label what each stage box output carries, usually a console aux, matrix or main bus.

Steps

  1. Open I/O Devices in the sidebar and open the device.
  2. Under I/O Device Outputs, tap the box under Out 1. The list shows the named outputs on this project's consoles, for example "Aux 3 · Wedge 3", "Mtx 1 · Delays" or "St L · Main L".
  3. Tap one, or type your own label (for example "Comms feed").
  4. Do the rest of the outputs, then press Save.

Good to know

  • You can also patch from the console page: tap a mix's Patch cell. Both ways make the same link.
  • Picking an aux, matrix or stereo bus links the output to it. Rename the bus and the label follows.
  • Typed labels are a name only. Editing a picked name drops the link. Clearing the box clears both.
  • "linked to … (unnamed)" in a box means it's patched to an unnamed bus. Leave it empty; typing over it unpatches it.
  • If the bus is deleted, the output keeps its label but loses the link.
  • One mix can feed outputs on several boxes.
