Each tab of the Wiring Diagram shows one part of the system. Set each I/O device's Console connection so its console links draw right.

Steps

  1. Pick a tab: Overview (everything), Dante and AVB (with IPs), Analogue/AES (cabled signal), Speaker cables or Comms.
  2. On the Overview, Show network feeds hides AVB and Dante feeds; slots still name the source.
  3. Open each I/O device's page and set Console connection (Dante, TWINLANe, MADI, Analog, Other). The Dante and Analogue/AES tabs list console-patched devices without one.
  4. A label too long to draw shows a key, [1]. Find it in Connections below.

Good to know

  • Grey dotted lines are console links with no Console connection set.
  • Console connection is per device, not per console.
  • Tabs are laid out separately.
  • Connections lists only the open tab's keys.
  • The Dante tab shows every device with Console connection Dante or a Dante network, and comm devices, grouped by network. A box patched only to comms links to the Comms tab.
  • AVB shows processors with AVB outputs and their amps.
  • On Dante and AVB, each port is one coloured, numbered trunk; a hollow badge is an inferred link. Hover or tap to highlight.
