Each tab of the Wiring Diagram shows one part of the system. Set each I/O device's Console connection so its console links are drawn right.

Steps

  1. Pick a tab: Overview (everything), Dante (with IPs), Analogue/AES (cabled signal), Speaker cables or Comms (the comms patch).
  2. On the Overview, Show network feeds hides AVB and Dante feeds; slots still name the source.
  3. Open each I/O device's page and set Console connection (Dante, TWINLANe, MADI, Analog, Other). The Dante and Analogue/AES tabs list console-patched devices without one.
  4. A label too long to draw shows a key, [1]. Find it in the Connections table under the diagram.

Good to know

  • Grey dotted lines are console links with no Console connection set.
  • Console connection is per device: one on TWINLANe to one console and Dante to another can't be shown yet.
  • Each tab is laid out on its own, so a box can sit in a different place on each.
  • The Connections table lists only the open tab's keys.
  • The Dante tab shows every device with Console connection Dante or a Dante network, and comm devices, grouped by network.
