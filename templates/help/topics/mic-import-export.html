Load a presenter list from a spreadsheet, and print or send the finished mic sheet.

Steps

  1. In the spreadsheet, put one name per row in column A, first and last name in the same cell. Save it as CSV.
  2. In the Mic Tracker press 👤 Presenters, then 📥 Import CSV.
  3. Choose the file under Select CSV File and press Import Presenters.
  4. To export, press ↓ Export CSV or ↓ Export PDF in the Mic Tracker header.

Good to know

  • Import only adds names to the presenter list. Assign them to mics on the A2 cards.
  • A header cell reading Name, Names, Presenter or Presenters is skipped. Other columns and empty rows are ignored.
  • Names already on the list are skipped, even if the capitals or spacing differ. The message tells you how many were imported and skipped.
  • The CSV covers every day and session in the project. Each session has the columns RF#, Presenter(s), Type, Headset Color, Placement, Sensitivity, Output Level and Notes, with one row per presenter. It doesn't include MIC'D status.
  • The PDF prints the A2 cards with photos, and each day starts on a new page.
