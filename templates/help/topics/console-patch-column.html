See which stage box port feeds each channel, and where each mix goes, from the console page.

Steps

  1. Open Consoles in the sidebar, open a console and open one of its grids.
  2. On a wide screen, Patch is a column after Source (B) on inputs and after Name on outputs. On a narrower screen, such as an iPad, press Patch next to Show: above the grid; Hardware switches back. This browser remembers your choice.
  3. Tap a device name to open that device.
  4. For spare ports, check I/O devices · free ports above the grids.

Good to know

  • A plain "Stage Left · In 12" means linked: the port was picked from the list on the device page.
  • by name: not linked, but the port's name matches this channel only. Pick it on the device page to make the link.
  • ambiguous (…): the name fits several channels or consoles, so it counts for none. Link it on the device page.
  • B: the port's name matches Source (B).
  • Amber: two or more ports are linked to one input. Outputs never go amber.
  • — means nothing is patched. This column is read-only; patch on the device page.
