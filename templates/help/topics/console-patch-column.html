Patch stage box ports from the console page, and see what feeds each channel.

Steps

  1. Open a console and a grid. On an iPad, press Patch next to Show: to see the Patch column.
  2. Tap a channel's Patch cell (+ Patch when empty).
  3. Under Choose an I/O device, tap a device; each shows its free ports.
  4. Tap a free port. Used ports are dimmed, with their name.
  5. Already patched? Choose Replace with …, or Add as second (conflict) on inputs, Add — feed both on outputs.
  6. To unpatch, tap the cell and press Unpatch.

Good to know

  • Same as patching on the I/O device page; use either.
  • Inputs patch the A Source only. Aux, matrix and stereo outputs can be patched.
  • Unnamed channel: the port takes its name when you name it and save. Typed but not saved: the port takes it now; until you save, the cell shows amber name not saved and leaving asks first.
  • by name: not linked, but the name fits only this channel. ambiguous (…): fits several, counts for none. Amber: two ports linked to one input.
  • Spare ports: I/O devices · free ports. Viewers see the patch read-only.
