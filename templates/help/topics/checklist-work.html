Track setup jobs and daily line checks for FOH, A2 and Prep, and see at a glance what is done.

Steps

  1. Open Audio Checklists in the sidebar.
  2. Pick a tab: FOH, A2 or Prep.
  3. Under Setup Tasks (One-Time), set each task's STATUS: Not Started, In Progress, Complete or N/A. The row colour changes to match.
  4. If you want, set STAGE to Pre-Production or Load-In.
  5. Under Daily Tasks, set a status in each day's column (for example the PA zone check on Day 2).
  6. For a paper copy, use Print, or Export to CSV to get all three lists as a spreadsheet.

Good to know

  • Every change saves as soon as you make it (a Saved note pops up), and everyone on the project sees the same list.
  • The first time a project opens the checklist, each list is filled with a starter set of tasks.
  • Prep has setup tasks only. It has no Daily Tasks column.
