Load the whole crew list in one go, so names are ready to pick on beltpacks and COMM Config roles.

Steps

  1. In your spreadsheet, put one name per row in column A, e.g. Sam Rivera. Other columns are ignored.
  2. Save it as a CSV in UTF-8.
  3. Open Comm Devices and click Crew Names.
  4. Click Import CSV, choose the file under Select CSV File, then click Import Crew Names.

Good to know

  • A first row that reads exactly Name, Names, Crew or Crew Name is treated as a header and skipped. Any other first row is imported as a name. If you are unsure, leave the header off.
  • Blank rows are skipped. A name that is already on the list is not added twice.
  • The names go into this project only.
  • Keep positions such as "GFX 1" in Positions, not Crew Names. Adding one by hand shows a warning.
  • A file saved in an encoding other than UTF-8 can fail on accented names.
