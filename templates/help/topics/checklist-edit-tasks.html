Make the FOH, A2 and Prep lists match how you actually run the show.

Steps

  1. Open Audio Checklists in the sidebar and pick a tab.
  2. To add a task, click + Setup Task or + Daily Task, type the name and press OK. It goes to the bottom of that column.
  3. To rename a task, click into its text, edit it and click away. It saves on its own.
  4. To move a task, use ▲ and ▼ in the Actions column.
  5. To delete a task, click × and confirm.

Good to know

  • Tasks only move within their own column. A setup task can't be turned into a daily task, so delete it and add it again in the other column.
  • Prep has no + Daily Task button.
  • A deleted task can't be brought back. Reset All restores the starter tasks, but it also wipes everything you added.
  • Your changes apply to this project only. To reuse your list on the next show, save it as a template.
