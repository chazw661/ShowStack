Add an L-Acoustics P1 and label its inputs, outputs and buses so the amp racks can pick up its signal names.

Steps

  1. Open System Processors in the sidebar and tap Add System Processor.
  2. Enter a Name, set Device type to L'Acoustics P1, pick a Location and add the IP address if you have it. Save.
  3. In the list, tap Setup P1 Configuration (it reads Configure P1 once set up).
  4. The P1 page lists 4 Analog, 4 AES/EBU and 8 AVB inputs, with the same outputs. Type a label for each input. Suggestions come from your I/O device output names.
  5. Label each output and pick its bus (Bus 1–Bus 8).
  6. Tap Save. You land back on System Processors.

Good to know

  • Labelled P1 outputs are offered as suggestions on amp inputs in Amplifier Assignments.
  • The Import Configuration file box doesn't read the file yet. Enter labels by hand.
  • Export PDF on the System Processors list prints every processor in the project.
