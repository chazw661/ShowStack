Load a Soundvision report so ShowStack can list every array's trim, weight, motor loads and box angles.

Steps

  1. Open Soundvision Predictions in the sidebar and tap Add Soundvision Prediction.
  2. Enter a File name so you can recognise it later. Pick a Show day if you want one.
  3. Under File Upload, choose the Soundvision PDF report in Pdf file.
  4. Save. You'll see "Successfully parsed …" or "Error parsing PDF: …".
  5. The Arrays column in the list shows how many arrays were read. Tap View Details to check them.

Good to know

  • The version and generated date are taken from the report when it has them.
  • The reader works from the PDF's text, so a scanned or image-only PDF gives no arrays.
  • Weights and motor loads are read in lb. A report in kg may come in with these blank [CHECK].
  • Uploading a new PDF to an existing prediction replaces all of its arrays. Any PA cable runs linked to the old arrays lose that link.
