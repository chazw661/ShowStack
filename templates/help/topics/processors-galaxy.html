Add a Meyer GALAXY and label its inputs and outputs, with the bus and destination for each output.

Steps

  1. Open System Processors and tap Add System Processor.
  2. Enter a Name, set Device type to Meyer GALAXY, pick a Location and add the IP address if you have it. Save.
  3. In the list, tap Setup GALAXY Configuration (it reads Configure GALAXY once set up).
  4. The page lists 8 Analog, 8 AES/EBU and 16 AVB/Milan inputs, with the same outputs. Type a label for each input. Suggestions come from your I/O device output names.
  5. For each output, enter a label, a Bus number and a Destination (e.g. "Amp 1 Ch 3").
  6. Tap Save to return to System Processors.

Good to know

  • The channel layout is the same 8/8/16 whichever GALAXY model you carry.
  • Labelled outputs are offered as suggestions on amp inputs in Amplifier Assignments.
  • The Import Configuration file box doesn't read the file yet.
