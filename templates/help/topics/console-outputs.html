Name the console's mixes, matrices and main buses, so stage box outputs, PDFs and the Rivage export pick the names up.

Steps

  1. Open Consoles in the sidebar and open the console.
  2. Tap the Console aux outputs heading. Type each mix in Name (for example "Wedge 1") and set Bus type to Fixed or Variable.
  3. For a stereo mix, set Mono stereo to Stereo on the odd row. Even rows show ↳ linked and follow the row above.
  4. Tap Console matrix outputs and do the same for your matrices.
  5. Tap Console stereo outputs and name each Buss: Stereo Left, Stereo Right and Mono.
  6. Press Save.

Good to know

  • A new console starts with 48 aux rows and 24 matrix rows, already numbered.
  • Autofill in the Dante number, Aux number and Matrix number headers numbers a run of rows for you.
  • Fill in Omni out if you want it on the console PDF.
  • Untick Multitrack to keep a bus out of multitrack sessions.
