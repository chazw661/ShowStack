When a run carries on from speaker to speaker, add each link after the home run so it is counted and drawn.

Steps

  1. In PA Cable Entries, open the run. Length (ft) and Cable are the home run: amp to the first speaker.
  2. Tap the chain button, Linked. The first link row appears under it.
  3. Give the link its own Qty, Cable and Length (ft), and a Note if it helps.
  4. Tap Add another Link for speaker 2 to 3, and so on. The arrows move a link earlier or later.
  5. Save.

Good to know

  • A new link starts at the run's Count. After that Qty is the link's own: changing Count does not change it.
  • A jumper link has no length.
  • Turning Linked off removes the links when you save, not before. Turn it back on to keep them.
  • Each link is a cable of its own in the totals, under its own type. A 75' run with a 25' link is a 100' and a 25'.
  • The PDF and CSV list each link under its run. The Wiring Diagram writes the chain on the run.
