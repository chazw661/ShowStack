Download your track list as a file your DAW opens with names and colours already set.

Steps

  1. Open Multitrack Sessions in the sidebar and click the session.
  2. Check the tick boxes. Only ticked tracks are exported, in the order shown.
  3. Click one of these:
    • Export to Reaper (.RPP) for a new Reaper project.
    • Export to Reaper (Track Template) to add the tracks to a project you already have. In Reaper, use Track › Insert track from template. The file must be in Reaper's TrackTemplates folder, or pick it with Open template…
    • Export to Nuendo Live (.nlpr) for a Nuendo Live project.
  4. Open the downloaded file in your DAW. The file is named after the session.

Good to know

  • Only colours you set on the swatch are exported. Console channel colours are not carried over.
  • Nuendo Live keeps Red, Orange, Yellow, Green, Sky Blue, Blue, Purple and Pink. White, Grey, Brown, Black and custom colours come in uncoloured.
  • The Reaper files carry track names and colours only. Set inputs and record-arm in Reaper.
  • If no tracks are ticked, you get This session has no enabled tracks. instead of a download.
